## 最终联合核验

用户补充的更早截图揭示，原公式在2026年2月至4月仍有约6%至12%偏差。原因包括遗漏业绩快报、排除了无完整TTM的新成分股市值，以及月中成分变更滞后。方法版本3改为全部成分股市值计入；正式报告前采用已公告快报，季度快报TTM=上年全年利润+本年累计利润-上年同期累计利润；正式报告覆盖对应报告期后优先用正式数据。缺乏完整利润仍暂按0利润，不能冒充已完整披露。

对两张周度截图及此前日频截图的50个同日PE样本，最终平均绝对百分比误差0.448%，最大1.953%（2026-02-13）。例如：2026-03-06为205.017（Choice205.96）；04-24为197.5711（Choice198.42）；10-28为76.8751（Choice76.37）；11-13为54.193（Choice54.36）。该结果证明所查样本明显改善，不证明全部历史或Choice专有聚合规则完全一致。7月24日和1月底至2月中的样本仍有约1.8%至2%误差。
