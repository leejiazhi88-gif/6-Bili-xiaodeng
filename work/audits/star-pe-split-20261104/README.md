# 科创50与科创综指剩余成分拆分核算

观察日2026-11-04，取此前最近2026-10-30的Tushare index_weight快照。科创综指583只、科创50 50只，50只全部包含在583只中；daily_basic匹配率100%。月度快照不保证11月4日实际逐日名单及权重不变。

## 结果

| 分组 | 股票数 | 股票总市值（亿元） | TTM归母净利润，含亏损（亿元） | 总市值/净利润 |

科创50成员占科创综指快照权重39.322%，占当日个股总市值39.22%，贡献本次重算利润23.14%；剩余成员贡献利润76.86%。因此同口径下确实能降低PE，但结果是55.72，不能直接得到中证官方36.72。

同口径按市值权重组合应为调和关系：1/PE合计 = 市值占比50/PE50 + 市值占比剩余/PE剩余，不能算PE的算术平均。代入未四舍五入的精确数据，合计为55.7175倍。这里用总市值占比39.22%，不是10月30日快照的指数权重39.322%。

## 口径差异的量级

- Tushare index_dailybasic 当日科创50 pe_ttm=94.4536；本次用50只股票总市值和缓存TTM利润（含亏损）算得94.453580，吻合到0.00002倍。此为该日结果吻合，不证明所有历史日期完全复现。
- 对同批个股只保留pe_ttm>0的股票，再以其总市值和total_mv/pe_ttm隐含利润汇总：科创50 61.66倍、剩余31.60倍、全部39.16倍。这个计算定义与含亏损法不同，也不是官方算法已验证的证明。
- 39.16倍比中证官方36.72倍高6.63%。官方还注明计算用股本，不能把总市值、指数计算用市值混为一谈，不能将剩余6.63%差异归因于唯一因素。
