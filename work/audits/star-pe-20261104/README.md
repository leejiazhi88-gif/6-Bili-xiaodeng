核算日期：2026-11-05。比较窗口：2026-10-29 至 2026-11-04。此为一次性核验，不替换页面官方 PE。

## 直接接口与股票范围

- 本次 Tushare `index_dailybasic` 查询 `000680.SH`、20261029—20261104，返回空记录。不能把空值理解为PE为零。
- `index_weight` 返回月度快照。10月29日采用此前最近的9月30日快照（579只），10月30日至11月4日采用10月30日快照（583只），不使用未来名单。月度快照无法保证每日最新成分，尤其10月29日已有一个月间隔。
- 各日成分股 `daily_basic` 匹配率100%；正PE计算仅覆盖当日378—383只股票，其余没有正PE，不推断这些股票全部亏损。逐股原值、快照权重与日期见 constituents.csv。

## 可重算的公式

1. 正PE股票的总市值法：先取个股 `pe_ttm > 0`，由 `total_mv / pe_ttm` 推回对应盈利，再算 `Σ总市值 / Σ盈利`。不是PE算术平均。表中的“总市值重算”使用此公式。
2. 月末权重法：同一正PE股票集合计算 `Σ权重 / Σ(权重 / PE)`。月末以外的日期仍使用最近月末固定权重，未还原日间股本、调样、复权和权重漂移，因此只是敏感性对照。
3. 归母净利润缓存法：仅选公告日不晚于观察日的财报，按四季度TTM汇总，包括亏损，再以相同股票总市值除以净利润。结果保存在 audit.json，作为另一种定义的敏感性对照，不宣称是官方算法。缓存核验至11月3日，不能保证11月4日新增财报完整；已缓存历史修订及实际公告日字段也限制严格时点复现。

## 结论与未解决项

- 可以用Tushare逐股重算一个明确定义的科创综指范围PE；不能说Tushare没有任何计算所需数据。缺的是直接指数PE序列及完整复现官方所需的日度计算股本/盈利处理口径。
- 10月30日同日权重快照的权重法为44.46倍，官方44.68倍，差约-0.49%。后续交易日的固定权重法差异扩大，不能据单日贴近就认定公式已被验证。
- 官方10月30日单张列出583只股票、PE44.68倍，且注明“指数指标均采用个股计算用股本计算得出”。其第一大权重688825为16.14%，与Tushare当日16.138%相符，支持快照身份，但不证明全体成分、每日股本和财报口径完全相同。
- 股票总市值、计算用股本、亏损及缺失PE处理、财报更新、月度名单与权重漂移均可能产生差异。目前没有证据把全部差异归结为某一个原因，也尚未核算科创50的同口径PE。之前将241.69与84.04的差异直接解释为估值差，证据不足。
- 页面继续用可与官方单张对账的官方PE，不把此次重算结果拼接成官方历史。

## 总览采样纠正

发现总览科创综指直接使用日频官方历史，创业板指/科创50使用年内7天分组。此前答复“三条都已周采样”不准确。本次只将总览科创综指PE套用相同的年内7天取最后样本规则；估值模块仍保留原有日频官方历史，并按实际口径说明。原始数据不改写。
